# حكاية حياة | Hekayat Hayah

لعبة محاكاة حياة عربية تعمل في المتصفح، مصممة للموبايل أولًا وباتجاه RTL.

## تشغيل اللعبة
- افتح `index.html` في متصفح حديث، أو انشر المستودع باستخدام GitHub Pages.
- الواجهة والتنسيقات في `index.html` و`style.css`.
- محرك اللعبة والأحداث وحفظ التقدم في `app.js`.
- التقدم يُحفظ تلقائيًا في `localStorage` على نفس المتصفح والجهاز.
- زر «تصدير الحفظ» يصنع ملف JSON للاحتفاظ بنسخة شخصية من التقدم.

## الأنظمة الحالية
- إنشاء شخصية تلقائيًا بأسماء وبلدان وأفراد عائلة مختلفين.
- التقدم بالعمر، ومصاريف الحياة، والراتب السنوي، والتقاعد، وشاشة ملخص نهاية الحياة.
- أحداث متغيرة بحسب العمر، بقرارات ونتائج واحتمالات مخاطرة.
- الدراسة والجامعة والتخصصات والوظائف وشروط التأهل وطلبات العلاوة.
- الأصول والمشتريات والصيانة والبيع.
- أفراد العائلة والأصدقاء وشريك الحياة وتفاعلات العلاقات.
- الطبيب والجيم والمكتبة والإجازات والعمل المجتمعي ومخاطر مخالفة القانون.
- واجهة عربية RTL، شريط حالة متحرك، وحفظ تلقائي.

## ملاحظة تقنية
منطق الشخصيات والأحداث في الإصدار الحالي محاكاة تكيفية محلية تعتمد على حالة اللاعب والاحتمالات؛ لا يتصل بنموذج ذكاء اصطناعي خارجي ولا يحتاج مفتاح API.

## الاختبارات
يعمل فحص تلقائي عبر GitHub Actions عند التغيير على الفرع `main`، بما في ذلك فحص صياغة JavaScript والتحقق من وجود ملفات اللعبة الأساسية.

## النشر على GitHub Pages
1. افتح [إعدادات Pages](https://github.com/GeKa121111/Bitlife-/settings/pages).
2. تحت **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/(root))، ثم اضغط **Save**.
4. بعد ما يخلص GitHub النشر، افتح: https://gek121111.github.io/Bitlife-/

كل تعديل جديد على ملفات الجذر سيظهر بعد تحديث نشر Pages.
