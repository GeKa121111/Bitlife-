# حياة | محاكي حياة عربي

لعبة محاكاة حياة نصية باللغة العربية، مصممة للموبايل أولًا واتجاه RTL. مستوحاة من نوع ألعاب محاكاة الحياة واتخاذ القرار، مع اسم وهوية ومحتوى أصليين.

## تشغيل اللعبة
- الموقع المنشور: https://geka121111.github.io/Bitlife-/
- افتح `index.html` في متصفح حديث، أو استخدم GitHub Pages.
- الواجهة والتنسيقات في `index.html` و`style.css`.
- محرك الحياة والأحداث والحفظ في `app.js`.
- التقدم يُحفظ تلقائيًا في `localStorage` على نفس المتصفح والجهاز.
- خيار «تصدير الحفظ» ينشئ ملف JSON للاحتفاظ بنسخة احتياطية.

## التثبيت والعمل دون اتصال

يمكن تثبيت «حياة» كتطبيق ويب من المتصفح الذي يدعم PWA. بعد أول زيارة متصلة بالإنترنت، تُخزَّن ملفات الواجهة الأساسية محليًا لفتح اللعبة دون اتصال؛ أما التقدم فيظل محفوظًا في `localStorage` على نفس الجهاز والمتصفح.

## الأنظمة الحالية
- إنشاء حياة وشخصية وعائلة وبلد ومدينة عشوائية.
- التقدم السنوي، أحداث عمرية، خصائص الصحة والسعادة والذكاء والمظهر.
- التعليم والمدرسة والجامعة والتخصصات والرسوم.
- الوظائف، متطلبات التأهل، الراتب والأداء والعلاوات والترقيات والتقاعد.
- مسارات خاصة: التمثيل والموسيقى وصناعة المحتوى والرياضة والقتال والكتابة والإخراج.
- العلاقات والأصدقاء والشريك والزواج والطلاق والأبناء، وتفاعل مستقل مع الأبناء.
- استمرار السلالة بعد الوفاة من خلال حياة أحد الأبناء، مع انتقال إرث ومقتنيات.
- العقارات والسيارات ومشروع تجاري، الصيانة وارتفاع/انخفاض القيمة.
- محافظ استثمارية بمخاطر مختلفة، القروض، الفوائد وسداد الديون.
- الحيوانات الأليفة ورعايتها، والهوايات وتنمية المهارات.
- السفر والهجرة وتغير بلد الإقامة والعملة.
- نظام جريمة وسجل قانوني واحتمالات غرامة أو سجن وأحداث داخل السجن.
- الشهرة والسمعة ورخصة القيادة والوصية.
- إنجازات، أشرطة ختامية، مكافأة يومية، مقتنيات عشوائية، ومقبرة تحفظ ملخصات الحيوات السابقة.
- تحديات يومية متجددة بثلاث مهام، مكافآت مالية وإحصائية، ومكافأة إضافية وسلسلة إنجاز عند إكمالها.
- وضع صانع الحياة: محرر للصحة والسعادة والذكاء والمظهر وسمات أفراد العائلة والأصدقاء.
- الرجوع بالزمن: حفظ آخر 8 نقاط سنوية والرجوع إلى عمر سابق، بما في ذلك استعادة المسار قبل الوفاة. نقاط الرجوع لا تكرر سجل الأحداث كاملًا، وتقرأ صيغة الحفظ الأقدم.
- ملفات المهن المتخصصة: سجل النجاحات والإخفاقات والدخل والأنشطة، وأرشيف للمسارات السابقة عند تغيير المهنة.
- استوديو إخراج أفلام: سبعة أنواع أفلام أصلية، ميزانيات إنتاج، أساليب إبداعية، حزم طاقم وتسويق، تقييم نقاد وإيرادات وجوائز، وأرشيف لأحدث 20 فيلمًا.
- مسيرة قتال متخصصة: رتب ونقاط دوري، نزالات شوارع، منافسات دوري، حركات متنوعة بأساليب ومزايا مقابلة، تدريب للقدرات، مدرب بعقد ومصاريف، إصابات وتعافٍ، وسجل آخر 30 نزالًا. تتصاعد الصعوبة بحسب الرتبة، والحركة المختارة تؤثر على نتيجة المواجهة، والراحة المجانية محدودة بمرة في سنة اللعبة.
- إنشاء حياة جديدة مع تخصيص النوع وبلد الميلاد، وتغيير بيانات الشخصية.
- واجهة عربية RTL، قوائم قابلة للتمرير، أزرار كبيرة للموبايل وحفظ تلقائي.

## آخر دفعة تطوير

تشمل آخر دفعة تحديات يومية، محررات سمات للشخصية والعلاقات، رجوعًا بالزمن بآخر 8 نقاط سنوية خفيفة، سجلًا للمهن المتخصصة، ومسيرة قتال أكثر عمقًا. يتأكد GitHub Actions من صياغة JavaScript واختبارات المحاكاة قبل النشر.

## فحوصات الجودة والنشر
- يفحص GitHub Actions صياغة `app.js` ويشغّل اختبارات المحاكاة واختبارات انحدار آلية عبر Node.js.
- تتحقق الاختبارات من الهوية العربية، وروابط ملفات الواجهة، وثبات مفتاح الحفظ القديم، وتطبيع الحفظ المستورد، وعرض العملة بحسب بلد الشخصية.
- ينشر سير عمل منفصل الموقع على GitHub Pages عند التحديث على الفرع `main`.
- هذه الفحوصات لا تُغني عن اختبار يدوي كامل داخل متصفح الهاتف.

## ملاحظات
- هذه محاكاة محلية تعمل في المتصفح؛ لا تحتاج حسابًا أو خادمًا أو مفتاح API.
- بيانات الحفظ تبقى على نفس الجهاز والمتصفح، ويمكن تصديرها يدويًا.
- المشروع ليس منتجًا رسميًا لـ BitLife أو Candywriter، ولا يستخدم شعاراتهم أو أصولهم التجارية.
