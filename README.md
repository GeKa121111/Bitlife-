# حياة | محاكي حياة عربي

لعبة محاكاة حياة نصية باللغة العربية، مصممة للموبايل أولًا واتجاه RTL. مستوحاة من نوع ألعاب محاكاة الحياة واتخاذ القرار، مع اسم وهوية ومحتوى أصليين.

## تشغيل اللعبة
- الموقع المنشور: https://geka121111.github.io/Bitlife-/
- افتح `index.html` في متصفح حديث، أو استخدم GitHub Pages.
- الواجهة والتنسيقات في `index.html` و`style.css`.
- محرك الحياة والأحداث والحفظ في `app.js`.
- التقدم يُحفظ تلقائيًا في `localStorage` على نفس المتصفح والجهاز.
- يحتفظ التطبيق بنقطة استعادة محلية من آخر حفظ سليم عند الانتقال إلى سنة جديدة أو بدء حياة مختلفة؛ إذا تعذّر تحليل الحفظ الأساسي أو افتقد الاسم/العمر الأساسيين، يحاول استعادة النسخة السابقة تلقائيًا. كما يرفض استيراد JSON قابل للتحليل لكنه يفتقد هوية الشخصية أو عمرًا صالحًا دون تغيير الحياة الحالية. يظل مفتاح الحفظ الأساسي `hekayat_hayah_save_v1` وإصدار البيانات `version: 1` كما هما.
- خيار «تصدير الحفظ» ينشئ ملف JSON للاحتفاظ بنسخة احتياطية خارج المتصفح، ويُبقي رابط التنزيل المؤقت متاحًا لحظة قصيرة قبل تنظيفه لتحسين التوافق مع متصفحات الهاتف.

## التثبيت والعمل دون اتصال

يمكن تثبيت «حياة» كتطبيق ويب من المتصفح الذي يدعم PWA. بعد أول زيارة متصلة بالإنترنت، تُخزَّن ملفات الواجهة الأساسية محليًا لفتح اللعبة دون اتصال؛ أما التقدم فيظل محفوظًا في `localStorage` على نفس الجهاز والمتصفح.

## الأنظمة الحالية
- إنشاء حياة وشخصية وعائلة وبلد ومدينة عشوائية.
- التقدم السنوي، أحداث عمرية، خصائص الصحة والسعادة والذكاء والمظهر.
- التعليم والمدرسة والجامعة والتخصصات والرسوم.
- الوظائف، متطلبات التأهل، الراتب والأداء والعلاوات والترقيات والتقاعد.
- مسارات خاصة: التمثيل والموسيقى وصناعة المحتوى والرياضة والقتال والرياضات الإلكترونية والكتابة والإخراج. مسيرة الألعاب الإلكترونية لها موهبة قابلة للتطوير، بطولات بنتائج ومكافآت، تجهيزات تؤثر على فرص الفوز، وعقود رعاية بدخل سنوي.
- العلاقات والأصدقاء والشريك والزواج والطلاق والأبناء، مع شجرة عائلة مرئية ومراحل تطور الأبناء من الروضة والمدرسة إلى الجامعة والاستقلال والعمل؛ دعم الدراسة والتوجيه المهني يغيّران فرص المستقبل.
- استمرار السلالة بعد الوفاة من خلال حياة أحد الأبناء، مع انتقال إرث ومقتنيات.
- العقارات والسيارات ومشروع تجاري، الصيانة وارتفاع/انخفاض القيمة.
- محافظ استثمارية بمخاطر مختلفة، القروض، الفوائد وسداد الديون.
- الحيوانات الأليفة ورعايتها، والهوايات وتنمية المهارات. موهبة الألعاب تُحفظ ضمن بيانات الحياة، وتُهيّأ تلقائيًا للحيوات القديمة التي لا تحتوي عليها.
- السفر والهجرة وتغير بلد الإقامة والعملة.
- نظام جريمة وسجل قانوني واحتمالات غرامة أو سجن وأحداث داخل السجن.
- الشهرة والسمعة ورخصة القيادة والوصية.
- إنجازات، أشرطة ختامية، مكافأة يومية، مقتنيات عشوائية، ومقبرة تحفظ ملخصات الحيوات السابقة.
- تحديات يومية متجددة بثلاث مهام، مكافآت مالية وإحصائية، ومكافأة إضافية وسلسلة إنجاز عند إكمالها.
- وضع صانع الحياة: محرر للصحة والسعادة والذكاء والمظهر وسمات أفراد العائلة والأصدقاء. سمات الوفاء والغيرة والاعتمادية تؤثر على استقرار الشريك، والكرم والاندفاع يؤثران في التفاعل. كل شخصية تحتفظ بدفتر آخر 12 تفاعلًا.
- الرجوع بالزمن: حفظ آخر 8 نقاط سنوية والرجوع إلى عمر سابق، بما في ذلك استعادة المسار قبل الوفاة. نقاط الرجوع لا تكرر سجل الأحداث كاملًا، وتقرأ صيغة الحفظ الأقدم.
- ملفات المهن المتخصصة: سجل النجاحات والإخفاقات والدخل والأنشطة، وأرشيف للمسارات السابقة عند تغيير المهنة.
- استوديو إخراج أفلام: سبعة أنواع أفلام أصلية، ميزانيات إنتاج، أساليب إبداعية، حزم طاقم وتسويق، تقييم نقاد وإيرادات وجوائز، وأرشيف لأحدث 20 فيلمًا.
- مسيرة قتال متخصصة: رتب ونقاط دوري، نزالات شوارع، منافسات دوري، حركات متنوعة بأساليب ومزايا مقابلة، تدريب للقدرات، مدرب بعقد ومصاريف، إصابات وتعافٍ، وسجل آخر 30 نزالًا. تتصاعد الصعوبة بحسب الرتبة، والحركة المختارة تؤثر على نتيجة المواجهة، والراحة المجانية محدودة بمرة في سنة اللعبة.
- إنشاء حياة جديدة مع تخصيص النوع وبلد الميلاد، وتغيير بيانات الشخصية.
- واجهة عربية RTL، قوائم قابلة للتمرير، أزرار كبيرة للموبايل وحفظ تلقائي.
- إعدادات عرض محلية للوضع الداكن وتكبير النص؛ تُحفظ في مفتاح مستقل ولا تغيّر صيغة حفظ الحياة القديمة.

- اتفاقات رعاية الأبناء بعد الطلاق أو الانفصال: إقامة أساسية معك أو رعاية مشتركة أو إقامة أساسية مع الطرف الآخر، مع نفقة سنوية قابلة للتعديل ومتأخرات وسجل تغييرات.

- شجرة العائلة: عرض الأجيال المسجلة، الأهل والإخوة والشريك والأبناء، مع فتح ملف أي فرد من الشاشة نفسها.
- تطور الأبناء: مراحل تعليمية، تحصيل دراسي واستعداد مهني واستقلال يتغير مع العمر؛ دعم الدراسة والتوجيه المهني ومساندة بداية الحياة العملية تغيّر فرص المستقبل.

## آخر دفعة تطوير

تشمل آخر دفعة تحديات يومية، محررات سمات للشخصية والعلاقات، رجوعًا بالزمن بآخر 8 نقاط سنوية خفيفة، سجلًا للمهن المتخصصة، مسيرة قتال، استوديو أفلام، شجرة عائلة وتطورًا تعليميًا ومهنيًا للأبناء. يتأكد GitHub Actions من صياغة JavaScript واختبارات المحاكاة قبل النشر.

## فحوصات الجودة والنشر
- يفحص GitHub Actions صياغة `app.js` ويشغّل اختبارات المحاكاة واختبارات انحدار آلية عبر Node.js.
- تتحقق الاختبارات من الهوية العربية، وروابط ملفات الواجهة، وثبات مفتاح الحفظ القديم، وتطبيع الحفظ المستورد، وعرض العملة بحسب بلد الشخصية.
- ينشر سير عمل منفصل الموقع على GitHub Pages عند التحديث على الفرع `main`.
- هذه الفحوصات لا تُغني عن اختبار يدوي كامل داخل متصفح الهاتف.


## متجر مزايا حياة

تحتوي القائمة الرئيسية على متجر مزايا أصلية يمكن فتحها بعملة اللعبة فقط؛ لا توجد مدفوعات حقيقية أو اشتراكات داخل هذا الإصدار. تُحفظ الملكيات في مفتاح محلي مستقل هو `hayah_permanent_perks_v1` لتستمر عند بدء حياة جديدة على المتصفح والجهاز نفسيهما، بينما يظل حفظ الحياة الأساسي `hekayat_hayah_save_v1` وإصدار البيانات `version: 1` دون تغيير.

- **خزنة التحديات:** تحتفظ بآخر 60 يومًا من التحديات وتتيح استعادة مهمة قديمة غير مستلمة مرة واحدة بمكافأة مخفضة.
- **حماة السلسلة:** حزمة من خمس وسائل حماية؛ كل واحدة يمكنها إنقاذ سلسلة التحديات عند تفويت يوم واحد.
- **ذاكرة الزمن الموسّعة:** ترفع عدد نقاط الرجوع من 8 إلى 60، مع حد ثابت لتفادي تضخم ملف الحفظ على الهاتف.
- **الطابع الذهبي:** ثيم أصلي قابل للتفعيل والإيقاف، وإعداداته لا تغيّر بيانات الحياة.
- **حزمة التمثيل الاحترافية:** تتيح إعلانات تجارية مدفوعة ووكيل أعمال وفرص اختبار أداء إضافية.
- **مركز المهن الشامل:** نقطة دخول للمهن الخاصة وعلاوة دخل 10% عند التفعيل.
- **درع العافية:** يمنع عدوى منقولة جنسيًا محاكية مرتبطة باختيار اختياري للبالغين داخل اللعبة؛ وتُعالج الحالة المسجلة عبر زيارة الطبيب داخل اللعبة.
- **الورشة الذهبية:** تمنع مصاريف الصيانة السنوية للسيارات وتحافظ على حالتها، مع بقاء انخفاض قيمة السيارة جزءًا من المحاكاة.
- **جواز العالم:** يلغي رسوم الانتقال عند الهجرة إلى وجهة متاحة داخل اللعبة.
- **حصالة المليون:** تبدأ الحياة الجديدة بمليون من عملة بلد الشخصية، وتضيف المبلغ نفسه عند بدء حياة الوارث.
- **تميمة الازدهار:** ترفع راتب الوظائف 20% عند تفعيلها.

تعمل الملكيات محليًا فقط ولا تُزامن بين الأجهزة؛ حذف بيانات الموقع من المتصفح قد يحذفها. المزايا مستوحاة من أفكار عامة في ألعاب محاكاة الحياة، مع أسماء ونصوص وهوية بصرية أصلية.

## ملاحظات
- هذه محاكاة محلية تعمل في المتصفح؛ لا تحتاج حسابًا أو خادمًا أو مفتاح API.
- بيانات الحفظ تبقى على نفس الجهاز والمتصفح، ويمكن تصديرها يدويًا.
- المشروع ليس منتجًا رسميًا لـ BitLife أو Candywriter، ولا يستخدم شعاراتهم أو أصولهم التجارية.

- اختبارات متصفح آلية عبر Chromium على مقاس موبايل 390×844: تحميل حفظ v1، التقدم سنة، إعادة التحميل، الرجوع بالزمن، تصدير/استيراد JSON صالح، ورفض JSON تالف أو ناقص الحقول الأساسية دون تغيير الحفظ الحالي، واستعادة نسخة احتياطية عند وجود حفظ رئيسي قابل للتحليل لكنه غير صالح بنيويًا. يشمل الاختبار نهاية الحياة واختيار وريث، وتركة متعددة الأصول لاختبار التقريب، وحالة الديون التي تتجاوز الأصول. هذا اختبار Chromium داخل CI وليس اختبارًا على هاتف Android فعلي.
